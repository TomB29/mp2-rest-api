Program Function

Simillar to the pipeline program in the previous project, the main.py program in this repository serves as a way to collate the functions of the smaller programs and models, found in src/, to complete opperate an API system. The main program is written as a series of endpoints from which the API can call routines as demanded through a browser window. The server for this window and the API are hosted locally on the device running the uvicorn module (currently my personal laptop for testing and implementation, but may be your local device if you access the program independantly), and the programs themselves respond to inputs from and return results to the browser window through the API. The testing functions (tests/test_api.py) serve as sytematic checks run without the need for global server systems, and can opperate entirely locally with the pytest fixtures found in tests/conftest.py
